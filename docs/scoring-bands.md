# 점수 밴드(1~5) 결정 기록 — 전처리 5개 항목

> 담당: 이수민 (전처리/데이터) · 최초 작성 2026-06-22
> 대상 항목: 발화 완결성(02) · 언어 일관성/말투(03) · 발화 속도(12) · 이해 확인 질문(16) · 참여 유도(17)

각 항목의 원지표 → 1~5 등급 변환 기준(score band)을 한곳에 정리한다.
점수 함수는 각 전처리 모듈에 위치한다(스코어러가 아니라 모듈 로컬 — 항목 12/16/17과 동일 패턴).

---

## 0. 적용 범위 (팀 안내, 2026-06-22)

- **현재는 단일 강사만 대상.** 강사 간 변별력(좋은 강사 vs 아쉬운 강사 구분) 검증은 지금 단계에서 불요.
- 따라서 밴드는 **강사 간 보정(calibration)이 아니라 절대 등급**으로 설계한다.
- **결과적 특성:** 한 강사의 실측 분포가 좁아(완결 72.2%±2.0, 일관 72.3%±4.6, 속도 편차 작음)
  15개 강의의 점수가 거의 일정하게 나온다. 이는 버그가 아니라 "일관된 강사"의 반영이다.
  점수의 쓸모는 **① 절대 등급, ② 주차별 trend**(2/2~2/27)이며, 강의별 출렁임(변별)은 단일 강사에선 원래 안 나온다.

## 2. 02 발화 완결성 — `sentencizer.completeness_score(rate)`

```
5: rate >= 80
4: 70 <= rate < 80
3: 60 <= rate < 70
2: 50 <= rate < 60
1:        rate < 50
```

**근거(잠정, 출판 아님):**
- 실측 15강의 완결률 69~72%(±2.0)를 "정상~양호(3~4)" 위치에 둠.
- 구어 강의 특성상 100% 완결은 비자연(자기수정·중단·되묻기가 정상) → 천장(80%+)을 낮게 잡음.
- 완결률 자체가 EDA로 보정된 값(갭 임계 10초→30초, `SEGMENT_GAP_SECONDS` 참고)임을 전제.

**현재 강사 결과 예시:** 2026-02-02 강의 rate=69.0% → **3점**.

## 3. 03 언어 일관성(말투) — `formality.consistency_score(ratio)`

```
5: ratio >= 90
4: 80 <= ratio < 90
3: 70 <= ratio < 80
2: 60 <= ratio < 70
1:        ratio < 60
```

`ratio = consistency_ratio = max(존댓말%, 반말%)` (중립=한다체 제외 분모).

**근거(잠정, 출판 아님):**
- "한 말투로 일관될수록 고점"이라는 단순 원칙.
- 실측 67~72%(존댓말/반말 ~72/28 혼용)는 2~3점대에 위치 — 혼용이 적지 않다는 판단.
- **`violation_count` 미반영:** 현재 비율만으로 채점. 위반 문장 수 가중 감점은 보류(향후 결정).

**현재 강사 결과 예시:** 2026-02-02 강의 ratio=67.7% → **2점**.

**튜닝 포인트:** 2점이 박하다고 판단되면 컷오프 하향(예: 60→55) 또는 밴드 폭 조정. 팀 협의 대상.

## 4. 정식화(잠정 → 확정) 조건

이 밴드들이 "잠정"인 이유와, 확정으로 전환할 트리거:

1. **02/03 컷오프의 외부 근거 확보** — 한국어 구어 강의 완결률/일관성 % 기준치(선행연구·전문가 라벨).
2. **(범위 확장 시) 강사 간 변별 검증** — 현재는 불요(0절)지만, 다강사로 확장하면 분포 기반 재보정 필요.
3. **03 violation_count 반영 여부** 결정.

→ 위 중 하나라도 진행되면 본 문서 + 해당 모듈 docstring 갱신.
