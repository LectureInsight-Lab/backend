> 담당: 이수민 (전처리/데이터) · 최초 작성 2026-06-22
> 대상 항목: 발화 완결성(02) · 언어 일관성/말투(03) · 발화 속도(12) · 이해 확인 질문(16) · 참여 유도(17)

각 항목의 원지표 → 1~5 등급 변환 기준(score band)을 한곳에 정리한다.
점수 함수는 각 전처리 모듈에 위치한다(스코어러가 아니라 모듈 로컬 — 항목 12/16/17과 동일 패턴).

## 0. 적용 범위 (팀 안내, 2026-06-22)

- **현재는 단일 강사만 대상.** 강사 간 변별력(좋은 강사 vs 아쉬운 강사 구분) 검증은 지금 단계에서 불요.
- 따라서 밴드는 **강사 간 보정(calibration)이 아니라 절대 등급**으로 설계한다.
- **결과적 특성:** 한 강사의 실측 분포가 좁아(Kiwi 기준 완결 96.5%±0.4, 일관 54.5%±3.4, 속도 편차 작음)
  15개 강의의 점수가 거의 일정하게 나온다. 이는 버그가 아니라 "일관된 강사"의 반영이다.
  점수의 쓸모는 **① 절대 등급, ② 주차별 trend**(2/2~2/27)이며, 강의별 출렁임(변별)은 단일 강사에선 원래 안 나온다.

## 2. 02 발화 완결성 — `item02_completeness.completeness_score(rate)`

> ⚠️ [2026-06-22 재보정] 형태소 분석기 Mecab→Kiwi 전환으로 분포가 크게 바뀜(6절 참고).

```
5: rate >= 93
4: 87 <= rate < 93
3: 78 <= rate < 87
2: 68 <= rate < 78
1:        rate < 68
```

**근거(잠정, 출판 아님):**
- Kiwi 실측 15강의 완결률 **평균 96.5%(σ0.4, 범위 95.7~97.2)** 를 "거의 완전(5)"에 둠.
- Mecab 시절 69~72% 는 **Mecab 오태깅으로 과소집계된 값**이었음(6절). Kiwi 가 구어 종결어미를
  정확히 잡아 실제 완결률이 높음이 드러남 → 밴드를 Kiwi 분포에 맞춰 상향.
- ⚠️ **변별력 약함:** 정확 태깅 하에선 유창한 강사의 완결률이 포화(≈96%)라 강의 간 차이가
  거의 없음(σ0.4). 절대 등급(이 강사는 완결성 우수) 확인용이며 변별 지표로는 약하다.

**현재 강사 결과 예시:** 2026-02-02 강의 rate=95.9% → **5점**.

## 3. 03 언어 일관성(말투) — `item03_consistency.consistency_score(ratio)`  (측정 검증됨, 점수 해석 대기)

> [2026-06-22] Mecab→Kiwi 재보정 + **측정 검증 완료**. 54%는 실제 코드스위칭 — 측정은 신뢰
> 가능. 남은 건 "혼용=감점?"의 루브릭 판단뿐(아래 검증 결과 참고).

```
5: ratio >= 90
4: 80 <= ratio < 90
3: 70 <= ratio < 80
2: 60 <= ratio < 70
1:        ratio < 60       # 주의: ratio = max(존,반)/(존+반) 이라 정의상 50~100% 범위
```

`ratio = consistency_ratio = max(존댓말%, 반말%)` (중립=한다체 제외 분모). **하한 50%**.

**근거 + 변경 경위(잠정, 출판 아님):**
- "한 말투로 일관될수록 고점"이라는 단순 원칙. 밴드 자체는 Mecab 시절과 동일(절대 기준 유지).
- 단 **실측값이 67~72%(Mecab) → 54.5%(Kiwi, σ3.4)로 하락.** 원인 두 가지:
  - (실측) Kiwi 가 강사의 실제 반말 종결어미(어/야/지/잖아)를 정확히 포착 — 코드스위칭이 잦음.
  - (버그수정) `시오`(하십시오체)를 반말로 보던 분류 결함 수정(소수 영향). [item03_consistency.py 참고]
- **`violation_count` 미반영** (향후 결정).

**✅ 검증 완료 (2026-06-22) — 측정은 유효:**
54.5%가 (a)진짜 코드스위칭인지 (b)Kiwi 과대분리 artifact인지 검증한 결과 **(a)가 주원인**:
- **반말 표본 30 감사**: ~90%가 진짜 해체(있어/돼/봐/왔어/거야/없어/뜻이야). 오절단(괜찮아←괜찮아요)은 소수.
- **분리기 영향**: Kiwi 가 kss 대비 문장을 +14%(3,343개) 더 쪼개 일관율을 4.6%p 낮춤 — 실재하나 **부차적**.
  (kss 분리로 바꿔도 59% 로 옛 67~72% 와 여전히 큰 차이 → 주원인은 분리기 아님.)
- **높임어간(시)+반말어미 혼용**: 반말의 6%뿐 (94%는 순수 해체) — "사실은 존댓말 의도"로 보기 어려움.
- 결론: **강사는 실제로 존/반 ≈50/50 혼용**. 옛 67~72%(Mecab)가 오태깅 artifact였음.

**✅ 점수 해석 결정 (2026-06-22): 현행 유지 — 혼용=감점.**
친근한 혼합 화법이라도 일관성을 엄격히 적용한다. 존/반 ≈50/50 은 최저점으로 확정.
(추후 팀이 재론하면 밴드/규칙 조정 가능. 측정값은 신뢰 가능하므로 재론은 "해석" 한정.)

**현재 강사 결과 예시:** 2026-02-02 강의 ratio=53.9% → **1점** (확정).

**튜닝 포인트:** 검증(3절) 후 컷오프/밴드 폭 또는 "해체 허용" 규칙을 팀과 확정.

## 6. 부록: 형태소 분석기 Mecab → Kiwi 전환 (2026-06-22)

**무엇:** sentencizer 의 형태소 분석·문장 분리를 Mecab(python-mecab-ko) + kss 에서
**Kiwi(kiwipiepy) 단일 엔진**으로 교체. ⚠️ 2026-06-11 팀 결정(Mecab) 변경분 — 공유 필요.

**왜:** Mecab(mecab-ko-dic)이 구어체 종결어미를 연결어미(EC)로 **오태깅**. 실측 15강의에서
문장의 **26%가 Mecab非EF → Kiwi EF** 로 갈렸고, 표본 검수 결과 **Kiwi 가 정답**:

| 문장 끝 | Mecab | Kiwi(정답) |
|---|---|---|
| …할게요 / 뭐냐 / API죠 / 고마워요 | EC (불완결) | EF (완결) |
| …같다 / 튜토리얼이야 / 있구나 / 봐라 | EC (불완결) | EF (완결) |

**영향(EDA 재보정 필요했던 이유):**
- 완결률(02): 69~72% → **96.5%** (Mecab 과소집계가 교정됨) → 밴드 상향(2절).
- 일관율(03): 67~72% → **54.5%** (반말 종결어미가 정확히 드러남 + 시오 버그 수정) → 3절 검증 대상.
- 호환 확인: Kiwi 정규화 표면형(ᆸ니다/ᆫ다/ᆯ까요)도 formality 의 endswith(요/죠·니다/니까·다)
  매칭과 일치. 단 `시오`(하십시오체) 누락 1건 발견 → 격식존댓말로 추가.

**부수 효과:** Mecab·kss 의존성 제거(단일 엔진), 처리 속도 향상, mecab-ko-dic 번들 불필요.
